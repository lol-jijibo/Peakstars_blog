# 注释规范

所有新增或修改的 **Java** 代码必须包含中文注释，格式如下：

## 实体类注释

```
/**
 * 对应数据库 xxx 表，封装 xxx 业务的核心字段。
 * 配合 MyBatis 完成 ORM 映射，由 Service 层组装后输出给前端。
 */
```

## 配置类注释

```
/**
 * 集中管理 xxx 模块的配置参数，如超时时间、连接池、开关等。
 * 被 Spring 容器加载后注入到各 Service 或 Controller 中使用。
 */
```

## 接口注释

```
/**
 * 定义 xxx 模块的对外契约，屏蔽底层实现细节。
 * 实现类按此接口编码，便于替换和单元测试。
 */
```

## 方法注释

```
/**
 * 此方法的目的与功能说明。
 * 此方法的实现思路与业务逻辑。
 */
```

## 约束

- 注释必须为 **两行**，第一行说明目的，第二行说明逻辑
- 注释中**不得出现** "业务目的"、"业务逻辑"、"目的："、"逻辑：" 等字样
- 注释内容用中文，简洁明了，紧扣业务核心
- 修改代码时同步更新注释，删除代码时同步删除注释
