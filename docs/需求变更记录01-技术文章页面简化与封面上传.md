## 需求一：简化技术文章页面布局

**问题**：页面含 Hero 统计区、浏览方式面板、右侧边栏，布局冗余分散注意力。

**方案**：移除全部统计/侧边栏，改为"一行一文"逐行流式布局，后台编辑选项全部可见。

### 移除项

- Hero 区（大标题 + 文章数/精选/作者/阅读 4 项指标）
- 右侧浏览方式面板
- 右侧边栏（分类/热读/活跃作者/高频主题）
- 三层差异化卡片布局

### 新页面结构

```
顶部导航 → 标题区（浏览模式胶囊 + 分类胶囊）→ 文章流（逐行统一格式）→ 页脚
```

### 每篇文章展示字段

| 字段 | 展示 | 字段 | 展示 |
|------|------|------|------|
| category | 彩色分类徽标 | highlights | 高亮强调色标签 |
| featured | 金色"精选"徽标 | tags | 普通标签 |
| isVip | 紫色"VIP"徽标 | author | 头像+姓名+角色 |
| isCollected | "已收藏"徽标 | readCount/like/collect/comment | 数据统计行 |
| isLiked | "已喜欢"徽标 | coverUrl | 右侧缩略图 |
| summary | 摘要段落 | publishedAt + readTime | 日期·时长 |

### 变更文件

| 文件 | 说明 |

## 需求二：封面图片本地上传

**问题**：封面地址为纯文本输入，操作不便。

**方案**：改为文件选择器上传图片，保留手动 URL 输入兜底。

### 数据流

```
文件选择器 → FormData → POST /api/admin/upload/cover → 校验 → ContentStorageService(MinIO) → 返回 { url }
```

### 后端

**AdminController** — 新增端点 `POST /api/admin/upload/cover`

- 接收 `MultipartFile`，校验：非空 / 图片类型 / ≤10MB
- 调用 `adminService.uploadCoverImage()`
- 成功返回 `{ url }`，失败返回错误信息

**AdminService** — 新增接口方法

```java
String uploadCoverImage(String fileName, InputStream is, long size, String contentType) throws Exception;
```

**AdminServiceImpl** — 实现

- 注入已有 `ContentStorageService`
- 委托 `contentStorageService.upload("cover", fileName, is, size, contentType)`

### 前端

**admin.js** — 新增 `uploadCoverImage(file)` 函数

- FormData + multipart 提交，不走 JSON

**AdminDashboardView.vue** — 表单改造

- 隐藏 `<input type="file" accept="image/jpeg,image/png,image/gif,image/webp,image/bmp,image/svg+xml">`
- 无封面时：虚线占位区（点击触发选择）
- 有封面时：预览图 + 删除按钮
- 上传中：遮罩 + "上传中…"
- 底部保留手动 URL 文本框兜底

**AdminDashboard.css** — 新增样式

- `.cover-upload-area` / `.cover-placeholder` / `.cover-preview` / `.cover-remove-btn` / `.cover-uploading` / `.form-input--cover-url`

### 校验规则

| 校验项 | 前端 | 后端 |
|--------|:----:|:----:|
| 文件非空 | ✅ | ✅ |
| 图片类型 | ✅ accept + JS | ✅ contentType |
| ≤ 10MB | ✅ | ✅ |

支持格式：JPG / PNG / GIF / WebP / BMP / SVG
